# Valid Palindrome (#125, Easy) https://leetcode.com/problems/valid-palindrome/
Constraints:
1 <= s.length <= 2 * 10^5
s consists only of printable ASCII characters.

Example 1:
Input: s = "A man, a plan, a canal: Panama"
Output: true

Example 2:
Input: s = "race a car"
Output: false

Example 3:
Input: s = " "
Output: true
